# 领域边界与运营规则

协调集体草场生态时序、农机作业、牧草批次和成员收益。嘎查收回统一经营权后，
所有资源占用与收益分配都以**追加式可追溯账本**为准，纸面登记不再是事实来源。

## 一、账本与可追溯性

- 所有决定只追加事件（JSONL 一行一事），事件含序号、类型、业务日期、登记日期、登记人和载荷。
- 每条记录包含上一条哈希，形成哈希链；序号断裂、断链或内容被改动都会在重放时报错。
- 服务不保存易失状态：启动（重启）时重放整条链重建地块、机器、任务、批次、库存与方案。
- 业务日期晚于登记日期视为补录（`backfill=true`），溯源文本中标注“离线补录”；
  业务日期不能晚于登记日期。

## 二、地块生态约束

- 地块登记边界（界桩描述）、面积，可退出经营。
- 每块地可设置休牧期、禁牧期，管制可解除；解除前与作业时间重叠即拒绝排产。
- **调度先满足生态要求**：必须先由生态监测人员确认草籽成熟并完成生态观察，
  且作业开始日不得早于草籽成熟日；然后才谈得上窗口、机器和班组。
- 作业必须落在任务窗口内；窗口可延期，延期原因留痕。

## 三、农机人员调度

- 农机有可用/故障状态：故障机不能排产，修复后恢复。
- 班组可解散，解散后不能派工。
- 作业生命周期：排产 → 开工 →（中断 ↔ 复工）→ 完工；可取消，可改期/改派。
- **任一地块同一时段只能有一个有效作业**；同一台农机、同一个班组在时间重叠时
  也不能出现于两个作业（半开区间相交判定）。已完工、已取消的作业不再占位。
- 农机故障时可中断在制作业、修复后改期；改期超出任务窗口须先延期任务；改派保留原作业痕迹。
- 一个收割任务对应一条作业生命周期；同一地块再次作业须另开任务。

## 四、牧草批次守恒

- 批次从称重开始：净重 = 毛重 − 皮重，毛重必须为正且大于皮重。
- 入库前可多次登记损耗，累计损耗必须小于净重。
- 入库量严格等于净重 − 累计损耗，不可重复入库。
- 优惠供应与对外销售都是出库；**累计出库不得超过入库结存**。
- 批次恒等式始终成立：

  ```
  入库量 = 净重 − 损耗量
  结存量 = 入库量 − 优惠出库 − 销售出库 ≥ 0
  ```

- 称重支持离线补录：业务发生在先、登记在后时标记补录，重放后数量依然守恒。

## 五、成员权益版本

- 成员股份按生效日期形成版本链：新版本生效日必须晚于上一版本。
- 成员退出自生效日起股份归零（保留历史版本，历史日期仍可还原）；重新入社追加新版本。
- 分配以“基准日当期有效股份”为准；草案发布前允许用纠错覆盖当期认定。

## 六、成本、务工与年度净收益

- 支出分销售成本、作业成本、公益支出；务工报酬关联到已完工作业。
- 支出与务工都必须**录入、确认分离**：录入人不能确认自己的单据，未确认单据不计入净收益。
- 年度净收益 = 当年对外销售回款 − 当年已确认支出（含已确认务工报酬）。
- 净收益为负不得形成分红方案；方案中的收入、支出、净收益是快照，之后的新事件不回改方案。

## 七、收益分配与职责分离

- 分配方案状态：草案（可反复纠错重算）→ 已发布（冻结）。
- 每股金额按当期有效股份计算，每户四舍五入到分，尾差并入最后一户，保证分配合计严格等于净收益。
- **负责录入产量（称重）的人不能独自确认含本人分红的方案**，须由其他财务人员发布。
- 发布后不得改数；发现错误只能新增调整单：
  - 补发：向成员补付；追缴：向成员追回。
  - 原始方案行保持不变，调整单列示原因与金额，实得 = 原分配 ± 调整。

## 八、溯源解释

每一笔牧民能拿到的东西都能还原成证据链（每条证据指向真实账本序号）：

- 分红：本人股份版本 → 当年逐笔销售（批次/任务/地块）→ 已确认支出与务工 →
  方案草案、纠错、发布、补发/追缴。
- 优惠牧草：出库单 → 入库确认 → 损耗登记 → 称重 → 任务与地块，并展示批次结存与守恒关系。
- 务工收入：生态前置确认 → 任务窗口 → 排产/开工/中断/改派/完工 → 农机故障修复 →
  务工单登记与第二人确认。

资料版本只能递增。参与方、事实和约束均不能为空，示例不得包含真实个人信息、账号或凭据。
